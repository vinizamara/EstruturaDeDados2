# 📚 Estrutura de Dados II

## 📌 Descrição

Este repositório contém os materiais de estudo, códigos de aula e exercícios práticos desenvolvidos durante a disciplina de **Estrutura de Dados II**. O objetivo principal é registrar a evolução do aprendizado em **JavaScript (Node.js)**, focando na análise, comparação e implementação de algoritmos de busca, métodos de ordenação, recursividade e estruturas de dados não lineares, como árvores binárias de busca.

## 📁 Estrutura do Repositório

- 📂 **aulas** → Exemplos práticos e códigos apresentados pelo professor durante as aulas.
- 📂 **exercicios** → Listas de exercícios e desafios práticos resolvidos ao longo do semestre:
  - 📂 `atividade01/`
  - 📂 `atividade02/`
- 📂 **data** → Massas de dados (vetores numéricos e vetores de objetos) utilizadas no teste e benchmark de desempenho dos algoritmos.
- 📂 **lib** → Módulos e implementações reutilizáveis de estruturas de dados (ex.: Árvore Binária de Busca - ABB).

## 🧠 Conteúdos Abordados

- **Algoritmos de Busca:** Busca Sequencial e Busca Binária (com suporte a comparação via funções callback).
- **Algoritmos de Ordenação:** Bubble Sort, Selection Sort, Merge Sort e Quick Sort (aplicados a vetores simples e vetores de objetos complexos).
- **Recursividade:** Conceitos fundamentais, chamadas recursivas e comparação entre abordagens iterativas e recursivas (ex.: Fatorial).
- **Estruturas de Dados:** Árvore Binária de Busca (ABB) — operações de inserção, remoção e percursos (in-order, pre-order e post-order).
- **Manipulação Avançada de Dados:** Filtragem, ordenação personalizada e geração de relatórios a partir de vetores de objetos.
